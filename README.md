# nagyrobi/esphome-components

External components for [ESPHome](https://esphome.io/).

```yaml
external_components:
  - source: github://nagyrobi/esphome-components
    components: [vnc]
```

| Component | Description |
|---|---|
| [`vnc`](components/vnc/README.md) | VNC server display and touchscreen — view and operate a device's screen over the network, on its own or as a second head alongside a physical panel. |
